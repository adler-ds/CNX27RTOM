WHAT IT DOES:
-------------
A web application that automatically assigns unique login credentials to users
based on their email address. Each email gets one set of credentials that 
persists across sessions. Includes a hidden admin panel for management.

DATA SOURCE:
-----------
Excel File: Connections - All Orgs.xlsx (RTOM tab)
- 25 login credentials extracted
- Columns: URL (A), Username (B), Password (D)

KEY FEATURES:
------------
✓ User enters email → Gets assigned credentials
✓ Same email = Same credentials every time
✓ Once assigned, credentials locked to that email
✓ Admin panel to view all assignments
✓ Admin can reset any assignment
✓ Search and filter functionality
✓ Ready for Heroku deployment

TECH STACK:
----------
- Next.js 16 (React framework)
- TypeScript
- Tailwind CSS
- Node.js 18+
- JSON-based storage (upgradable to PostgreSQL)
